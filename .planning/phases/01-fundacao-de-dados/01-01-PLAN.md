<objective>
Criar a base de dados estruturada (planilha modelo) e o guia de modelagem que permitirá construir o modelo de dados em esquema estrela no Power BI.

Purpose: Todas as fases seguintes (Operacionais, Frota, Financeiros, Segurança) dependem de dados brutos bem estruturados e de um modelo de dados correto no Power BI. Sem essa fundação, qualquer indicador construído depois fica frágil ou incorreto.
Output: Planilha modelo (.xlsx) com abas para cada domínio de dado, um guia passo a passo para conectar essa planilha ao Power BI e montar o modelo estrela (dimensões + fatos), e confirmação do usuário de que o modelo está funcionando.
</objective>

<task type="auto">
  <name>Task 1: Criar planilha modelo estruturada</name>
  <files>dashboard/dados/planilha-modelo-transportadora.xlsx</files>
  <action>
  Usar a skill `xlsx` para criar um workbook com 5 abas, cada uma formatada como Tabela do Excel (Ctrl+T / ListObject, não intervalo solto), sem células mescladas e sem fórmulas manuais nos dados brutos (dado bruto puro, cálculo fica no Power BI):

  1. **Viagens** — colunas: ID_Viagem, Data_Saida, Data_Chegada_Prevista, Data_Chegada_Real, ID_Veiculo, ID_Motorista, ID_Cliente, Rota, Km_Rodado, Status_Prazo (No Prazo/Atrasado), Status_Completude (Completo/Avaria/Falta_Item), Tempo_Parada_Horas, Viagem_Programada (Sim/Nao)
  2. **Veiculos** — colunas: ID_Veiculo, Placa, Ano_Fabricacao, Km_Acumulado, Status (Ativo/Manutencao/Parado), Data_Status
  3. **Custos** — colunas: ID_Custo, Data, ID_Veiculo, Categoria (Combustivel/Manutencao_Preventiva/Manutencao_Corretiva/Fixo/Outro), Valor, Litros_Combustivel (preencher só quando Categoria=Combustivel)
  4. **Ocorrencias** — colunas: ID_Ocorrencia, ID_Viagem, Tipo (Atraso/Avaria/Extravio/Recusa), Data, Descricao
  5. **Telemetria** — colunas: ID_Evento, ID_Motorista, ID_Veiculo, Data, Tipo_Evento (Excesso_Velocidade/Freada_Brusca/Aceleracao_Brusca), Km_Rodado_Periodo, Horas_Direcao_Continua, Horas_Descanso

  Preencher cada aba com 2-3 linhas de exemplo (dado fictício, plausível) para servir de linha de teste na importação do Power BI. Adicionar uma aba README como primeira aba explicando o propósito de cada aba e a regra "não mesclar células, não inserir fórmula na tabela bruta — cálculo é feito no Power BI".
  </action>
  <verify>Arquivo dashboard/dados/planilha-modelo-transportadora.xlsx existe, abre sem erro, e cada uma das 5 abas de dado está formatada como Tabela nomeada com pelo menos 2 linhas de exemplo</verify>
  <done>Planilha modelo criada com as 5 abas de dado + aba README, estrutura tabular limpa, pronta para ser apontada como fonte no Power BI</done>
</task>

<task type="auto">
  <name>Task 2: Escrever guia de modelagem Power BI (esquema estrela)</name>
  <files>dashboard/GUIA-POWERBI-FASE1.md</files>
  <action>
  Escrever um guia passo a passo (em português, para um gestor não-técnico) cobrindo:

  1. Como conectar o Power BI Desktop à planilha `planilha-modelo-transportadora.xlsx` (Obter Dados → Pasta de Trabalho do Excel → selecionar as 5 tabelas de dado, não a README)
  2. Como recomendamos salvar a planilha no OneDrive/SharePoint para permitir atualização automática do dataset (~1h) mesmo sem licença Power BI Pro, conforme STACK.md
  3. Definição do modelo em esquema estrela a ser montado no Power BI:
     - Dimensões a criar: `dCalendario` (gerada via Power Query, cobrindo o intervalo de datas de Viagens), `dVeiculo` (a partir da aba Veiculos), `dMotorista` (extraído de Viagens/Telemetria — listar IDs únicos), `dCliente` (extraído de Viagens — listar IDs únicos)
     - Fatos: `fViagens` (a partir da aba Viagens), `fCustos` (a partir da aba Custos), `fOcorrencias` (a partir da aba Ocorrencias), `fTelemetria` (a partir da aba Telemetria)
     - Relacionamentos: cada fato se relaciona com as dimensões pela chave correspondente (ID_Veiculo, ID_Motorista, ID_Cliente, Data → dCalendario), todos 1-para-muitos (dimensão → fato), direção de filtro única
  4. Passo a passo de como criar cada relacionamento na view "Modelo" do Power BI (clique e arraste entre chaves)
  5. Como validar: criar uma tabela/matriz simples de teste (ex: Km_Rodado por dCalendario[Mes]) e confirmar que os números batem com a planilha de origem
  6. Como expor a data/hora da última atualização no relatório (medida DAX simples: `Ultima_Atualizacao = NOW()` num cartão, ou usar a informação de refresh do Power BI Service)

  Incluir os scripts de Power Query (M) necessários para gerar `dCalendario` e extrair listas únicas de motorista/cliente.
  </action>
  <verify>Arquivo dashboard/GUIA-POWERBI-FASE1.md existe e contém, nesta ordem: conexão de dados, definição do modelo estrela (dimensões/fatos/relacionamentos), script Power Query para dCalendario, passo de validação, passo de exibição de última atualização</verify>
  <done>Guia completo o suficiente para o usuário montar o modelo no Power BI Desktop sem precisar de conhecimento prévio de modelagem de dados</done>
</task>
